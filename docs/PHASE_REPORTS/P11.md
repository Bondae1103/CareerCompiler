## Done (with evidence)
- **Authoritative Canonical Master Profile Bank (`careercompiler/storage/canonical.py`)**:
  - Implemented `build_canonical_profile()` representing the candidate's complete, verified background aligned with `templates/resume.tex` slots (`exp_1_slot_1..3`, `exp_2_slot_1..2`, `proj_1_slot_1..3`, `proj_2_slot_1..2`, `proj_3_slot_1..2`).
  - All tags validated against the formal taxonomy catalog (`playwright`, `oop`, `rest-api`, `agentic-ai`, `ci-cd`, `docker`, `fastapi`, `pytorch-geometric`, etc.).
- **Command-Line Interface (`careercompiler/cli/main.py`)**:
  - Registered console script `careercompiler` in `pyproject.toml`.
  - Implemented subcommands:
    - `profile show`: Displays structured candidate summary, accomplishment slots, and variant counts.
    - `profile export`: Exports profile bank to JSON.
    - `profile import`: Imports and validates profile bank from JSON.
    - `parse-jd <jd>`: Decomposes JD text or file path into hard and preferred requirements.
    - `compile --jd <jd>`: Executes end-to-end closed-loop optimization, builds single-page verified PDF with Tectonic, and generates markdown review diff report.
    - `diff --jd <jd>`: Calculates selection diffs and ATS score deltas directly without PDF compilation.
    - `serve`: Launches Uvicorn web server hosting both the REST API and the React SPA.
- **Production REST API (`careercompiler/api/app.py`)**:
  - Built with FastAPI, CORS middleware, and Pydantic schema validation.
  - Endpoints:
    - `GET /api/health`: Health status and version verification.
    - `GET /api/profile` & `PUT /api/profile`: Profile retrieval and updates with repository persistence.
    - `POST /api/jds/parse`: Structured requirement extraction.
    - `POST /api/tailor`: Executes `ClosedLoopOptimizer`, enforces Truth Invariant, builds PDF, and computes `SelectionDiff` with ATS score deltas.
    - `POST /api/revert`: Executes 1-click slot rollback or bulk rollback with `RevertManager`, audit logging to `diff.revert_history`.
    - `GET /api/pdf` & `GET /api/tex`: Direct downloads for verified PDF artifact and rendered LaTeX source.
    - Static SPA serving: Mounts `frontend/dist` at `/` for seamless single-server deployment.
- **Modern React + Vite Web Dashboard (`frontend/`)**:
  - Initialized React 19 + TypeScript + Vite architecture with zero external UI dependency bloat.
  - Components implemented:
    - `Navbar.tsx`: Real-time backend connectivity badge, tab navigation, and candidate profile info.
    - `MasterProfileView.tsx`: Complete profile bank explorer with collapsible slots, variant metrics, default badges, and canonical tag pills.
    - `JDIntake.tsx`: Rapid testing presets (Distributed Systems, AI/LLMs, Bioinformatics), raw JD textarea, line capacity slider (15-40 lines), and requirement extraction chips.
    - `ATSScoreboard.tsx`: Optimization lift indicator ($\Delta_{\text{total}}$), multi-component breakdown cards (lexical, BM25, semantic cosine, budget efficiency), and requirement coverage checklist.
    - `DiffInspector.tsx`: Side-by-side slot comparison cards with action badges (`[SWAPPED]`, `[ADDED]`, `[OMITTED]`, `[UNCHANGED]`), tag deltas, 1-click slot revert buttons, bulk revert, and immutable rollback audit trail table.
    - `TexViewer.tsx`: In-browser syntax viewer with clipboard copy, `.tex` file download, and direct PDF download link.
  - Built production bundle (`frontend/dist`) via `tsc -b && vite build`.
- **Comprehensive Integration Test Suite**:
  - `tests/test_api.py`: 6 integration tests covering health, profile, parse, tailor, revert, TeX/PDF download, and static UI mounting.
  - `tests/test_cli.py`: 3 CLI tests covering profile show, parse-jd, and compile workflows.
