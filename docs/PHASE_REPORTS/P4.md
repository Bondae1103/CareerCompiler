  - Single canonical ID namespace with pattern `^[a-z0-9_-]{1,64}$`, resolving ambiguity between JD extractions and resume tags.

  - Curated **209 reviewed entities** with declared license provenance:
    - **GitHub Linguist** (34 entities, MIT License).
    - **Stack Overflow Tag Synonyms** (103 entities, CC-BY-SA-4.0).
    - **Official Project Specifications** (72 entities, permissive open source).
  - Exact count: **209 entities, 0 unreviewed entries**.
  - Generated reproducible `seed_taxonomy.json` and `provenance_manifest.json` via `scripts/generate_seed_taxonomy.py`.
- **Ingestion Pipeline for Scale (`careercompiler/taxonomy/ingest.py`)**:
  - Implemented `load_seed_taxonomy()`, `ingest_records()`, and `export_taxonomy()`.
  - Enforced strict license whitelisting (`MIT`, `CC-BY-SA-4.0`, `CC0-1.0`, `Apache-2.0`, `permissive_open_source`).
- **Boundary-Safe, Token-Aware Trie Matcher (`careercompiler/taxonomy/matcher.py`)**:
  - Dual Trie indexing (case-sensitive for ambiguous terms; case-insensitive for unambiguous terms).
  - Longest-match-first multi-term disambiguation (`JavaScript` before `Java`, `C++` before `C`, `React Native` before `React`, `Docker Compose` before `Docker`).
  - Strict boundary assertion handling special punctuation (`C++`, `C#`, `.NET`, `Node.js`, `RESTful APIs`, `CI/CD`, `Linux/POSIX`, slashes, brackets, quotes) preventing substring false positives (`Django` does not match `Go`, `MongoDB` does not match `Go`, `Reactive` does not match `React`).
  - Data-driven disambiguation rules for ambiguous short terms (`Go`, `C`, `R`, `Rust`, `Spark`, `REST`): context keywords, trigger patterns, and negative patterns (e.g. `let's go`, `go to`, `R&D`, `rust belt`, `spark of`, `the rest of`).
- **Normalizer API (`careercompiler/taxonomy/normalizer.py`)**:
  - `TaxonomyNormalizer.normalize(text) -> list[EntityMatch]`.
  - `TaxonomyNormalizer.canonicalize(term) -> str | None`.
  - Process-wide cached singleton `get_default_normalizer()`.
