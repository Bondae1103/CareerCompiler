# Phase P9 Report — Selector / Optimizer: ILP Formulation, Closed-Loop Verification & Truth Invariant

## Done (with evidence)
- **Exact ILP Bullet Selection Engine (`careercompiler/optimizer/solver.py`)**:
  - Implemented `ILPOptimizer` using Google OR-Tools CP-SAT (`ortools.sat.python.cp_model`) with single-threaded search (`num_search_workers=1`) and deterministic random seed (`seed=42`).
  - Integer-scaled multi-objective optimization function ($1000 \cdot \text{ReqScore} + 10 \cdot \sum \text{utility} - 1 \cdot \text{lines}$) aligning coverage maximization, utility maximization, and compact layout tie-breaking.
  - Multi-level constraint satisfaction:
    - Slot exclusivity: at most 1 variant per slot ($\sum x_{s, v} \le 1$), or exactly 1 if mandatory or pinned ($\sum x_{s, v} = 1$).
    - Entity bounds: $\text{min\_bullets} \le \sum x_{s, v} \le \text{max\_bullets}$.
    - Line capacity budget: total estimated lines $\le \text{capacity\_lines}$.
    - Submodular requirement linking: $cov_r \le \sum_{v \in \text{matches}} x_{s, v}$ and $cov_r \ge x_{s, v}$ ensuring diminishing marginal returns.
  - Structured infeasibility diagnostic engine analyzing constraint conflicts and pinpointing `LINE_BUDGET`, `MAX_BULLETS_CONFLICT`, `MIN_BULLETS_UNSATISFIABLE`, or `CONSTRAINTS_CONFLICT` with exact line deficits and conflicting slot IDs.
- **Combinatorial Reference Optimizer & Exact Parity Harness (`careercompiler/optimizer/brute_force.py`)**:
  - Implemented `BruteForceOptimizer` performing exhaustive combinatorial exploration over the power set of slot-variant combinations.
  - Validated exact bit-level objective value parity against CP-SAT across 220 randomized instances (`tests/test_optimizer_brute_force_parity.py`).
- **Closed-Loop Compile Verification Pipeline (`careercompiler/optimizer/pipeline.py`)**:
  - Implemented `ClosedLoopOptimizer` orchestrating solver, `ResumeTemplate`, and `LayoutVerifier`.
  - Dynamic line budget backoff: if layout verification detects page overflow ($> 1$ page), automatically decrements line budget by 1 and re-solves (up to 5 iterations).
  - Integrates `FontMetricSimulator` for automatic line cost estimation when variants lack static line annotations.
- **Byte-for-Byte Truth Invariant Enforcement**:
  - Implemented `ClosedLoopOptimizer.verify_truth_invariant()`.
  - Asserts that every emitted bullet in `selection.selected_bullets` maps to a known authored bank variant and matches its text byte-for-byte.
  - Rejects fabricated variant IDs and tampered/hallucinated text with explicit `TruthInvariantViolationError`.
