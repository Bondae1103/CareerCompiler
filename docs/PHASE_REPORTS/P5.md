# Phase P5 Report — Tier 3: Constrained Semantic Extractor (JD)

## Done (with evidence)
- **JD Chunk Output Schema (`careercompiler/extraction/models.py`)**:
  - Implemented strict Pydantic v2 models: `ExtractedJD`, `ExtractedRequirement`, `RequirementCategory` (`must_have` vs `nice_to_have`), and `ScaleIndicator`.
  - Enforced `extra="forbid"` on all models.
  - Verified span invariants: `0 <= start < end`, `len(evidence_text) == (end - start)`.
- **Deterministic Provider Interface & Caching (`careercompiler/extraction/base.py`, `careercompiler/extraction/cache.py`)**:
  - Defined `BaseJDExtractor` abstract base class.
  - Implemented deterministic SHA-256 caching: `sha256(jd_text + extractor_version + config)`.
  - Built two-tier local cache `ExtractionCache` (in-memory fast lookup + persistent JSON on disk).
- **Standalone Offline Rule Extractor (`careercompiler/extraction/rule_extractor.py`)**:
  - Operates 100% offline with zero network or remote LLM calls (satisfies D-010).
  - Uses Tier 1 `parse_job_description()` for hierarchical structure and Tier 2 `TaxonomyNormalizer` for boundary-safe entity matching.
  - Rule-based qualification categorization using section classifications (`REQUIREMENTS`, `PREFERRED`, `RESPONSIBILITIES`) and cue phrases (`must have`, `required`, `minimum`, `preferred`, `plus`, `bonus`).
  - Extracted explicit required experience years (`X+ years`) and scale indicators (`throughput`, `users_or_records`, `data_volume`, `cluster_size`) with exact spans.
  - Role title detection from explicit markers ("Job Title:", "Role:", "Position:") or prominent heading items.
- **Strict Post-Validator & Prompt-Injection Defense (`careercompiler/extraction/validator.py`)**:
  - Validates that every extracted requirement and scale indicator carries character offset spans into the source text where `source[start:end]` contains the surface form and exact qualification.
  - Enforces prompt-injection defense: adversarial attempts to elevate importance are capped by cue phrase limits (`CUE_PHRASE_MAX_IMPORTANCE`).
  - Hallucinated entities, out-of-bounds spans, or unverified experience years are dropped and counted in `dropped_items_count`, logging audit warnings in `validation_warnings`.
  - Schema fuzzing resilience: malformed types, missing fields, and inverted spans never crash the engine.
- **Optional LLM Extractor Protocol (`careercompiler/extraction/llm_extractor.py`)**:
  - Implemented `LLMExtractor` requiring explicit user opt-in (D-010).
  - Post-validates all model responses and gracefully falls back to `LocalRuleExtractor` upon failure or retry exhaustion.
- **Corpus Evaluation across 10 Real JDs (`eval/p5_corpus_extraction_eval.py`)**:
  - Evaluated on all 10 authentic real JDs: 49 hard requirements, 12 preferred qualifications, 61 candidate items.
  - **100.00% Evidence Span Validity**: every extracted requirement and scale indicator points to exact, unmodified source text.
  - **0 Dropped Items** on authentic real JDs.
  - **11.44 ms** average extraction latency per complete Job Description.
