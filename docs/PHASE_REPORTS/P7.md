# Phase P7 Report — Scoring (BM25 + Semantic + Lexical Coverage + Quality)

## Done (with evidence)
- **Scoring Documentation & Mathematical Models (`docs/SCORING.md`)**:
  - Detailed mathematical models for Submodular Lexical Coverage, Okapi BM25 relevance, Semantic Cosine Similarity, Metric Quality Aggregation, and Single-Bullet Slot Utility $U(b)$.
  - Documented BM25 background corpus comparison and rationale for selecting `bank_plus_jd`.
  - Defined the strict **Explainability Invariant** ($S_{\text{total}} = \sum_c \text{contribution}_c$).
- **Versioned TOML Configuration (`careercompiler/scoring/scoring.toml`)**:
  - All weights, hyperparameters, quality bonus values, and scaling factors externalized with zero magic constants in code.
  - Initial calibration status recorded as `UNCALIBRATED`.
- **Submodular Lexical Coverage Scorer (`careercompiler/scoring/lexical.py`)**:
  - Implemented set-based requirement matching with category weighting (`must_have: 1.0`, `nice_to_have: 0.5`).
  - Guaranteed submodularity: each requirement is counted at most once regardless of frequency.
  - Implemented `marginal_delta` calculating the exact incremental gain of a candidate bullet.
- **Deterministic Okapi BM25 Scorer (`careercompiler/scoring/bm25.py`)**:
  - Implemented pure Python BM25 indexer with $k_1 = 1.5, b = 0.75, k_{\text{norm}} = 5.0$.
  - Domain-preserving tokenization preserving `C++`, `C#`, `.NET`, and `Node.js`.
  - Supports configurable corpus modes (`bank_plus_jd`, `bank_only`, `jd_only`).
- **Deterministic Offline Semantic Scorer (`careercompiler/scoring/semantic.py`)**:
  - Built `DeterministicHashingEmbedder` using character and subword n-gram feature hashing into a 128-dimensional unit hypersphere.
  - Zero external network or heavy neural dependency required for baseline scoring.
  - Cosine similarity evaluation across all JD requirement embeddings.
- **Resume Scoring Orchestrator (`careercompiler/scoring/scorer.py`)**:
  - `ResumeScorer` coordinates Lexical, BM25, Semantic, and Quality evaluations.
  - Enforces the Explainability Invariant: `ScoreBreakdown.total_score` strictly equals the sum of `component_contributions`.
  - Implemented `score_bullet_utility` calculating multi-factor ranking utility $U(b)$ with overflow line penalty.
- **Calibration & Ablation Harness (`eval/p7_ablation_eval.py`, `tests/test_p7_ablation.py`)**:
  - Evaluated scoring progression (Lexical Only -> +BM25 -> +Semantic -> Full) across 10 authentic real JDs.
  - Verified that partial terminology and semantic affinities surface relevant bullets even when exact gazetteer keywords are absent.
