# Phase P6 Report — Resume Bullet Decomposition (ACTR) & Metric Quality

## Done (with evidence)
- **Scoring and Metric Quality Documentation (`docs/SCORING.md`)**:
  - Documented 4 metric quality tiers: `NONE`, `VAGUE`, `QUANTIFIED`, `QUANTIFIED_WITH_BASELINE`.
  - Defined explicit mathematical scoring formulas for metric quality utility ($Q(b)$), keyword coverage, semantic relevance, and length/penalty terms.
- **Decomposition Models (`careercompiler/decomposition/models.py`)**:
  - Defined `ImpactMetric`, `ActionVerb`, `DomainConcept`, `BulletDecomposition`, and `MetricQuality` enum.
  - Enforced `extra="forbid"` and non-negative character offset spans with `0 <= start < end`.
  - Provided `reconstruct_bullet_text()` satisfying the Truth Invariant (reconstructed text is byte-identical to original authored bullet text).
- **Empirical Metric Extraction & Normalization (`careercompiler/decomposition/metrics.py`)**:
  - Implemented deterministic regex and grammar rules for 8 metric categories:
    1. Baseline Transitions (`from X to Y` with baseline and end values, direction)
    2. Throughput / Ops (`ops/sec`, `TPS`, `req/s`, `QPS`, `RPS`)
    3. Latency (`ms`, `milliseconds`, `seconds`, `p99`, `p95`)
    4. Percentages (`%` with float normalization)
    5. Multipliers (`2x`, `10x`, `3.5x`)
    6. Currency (`$`, `€`, `£` with `k`/`M`/`B` multipliers)
    7. Scale Counts (`158K-neuron`, `13,753 clinical isolates`, `10M+ users`, `50+ attendees`)
    8. Framerate / Frequency (`60fps`, `Hz`, `kHz`)
  - Built strict negative exclusions disqualifying:
    - Software versions (`Python 3.11`, `PostgreSQL 16`, `v1.0`, `YOLOv8`)
    - Calendar years & dates (`Sep 2023`, `2026`, `since 2019`, `in 2027`)
    - Availability metrics (`24/7`)
    - Phone / contact numbers
  - Metric quality classifier labeling bullets into the 4 tiers.
- **Action Verb & Technology Grounding (`careercompiler/decomposition/verbs.py`, `careercompiler/decomposition/decomposer.py`)**:
  - Extracted opening action verbs with lemmatization, tense detection (past, present, participle), and character spans.
  - Boundary-safe technology recognition matched against Tier 2 Gazetteer with exact character spans matching `source[start:end] == surface_form`.
  - Batch decomposition across an entire profile (`decompose_profile`).
- **Comprehensive Verification Suite**:
  - Table-driven metric tests covering all 8 categories.
  - 17 negative exclusion test cases ensuring zero false positives on software versions, dates, 24/7, and contact info.
  - Hypothesis property tests verifying span validity and normalization properties.
  - Authentic profile bullets test verifying 100% Truth Invariant preservation on user resume bullets.
