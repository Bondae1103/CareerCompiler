# Phase P8 Report — Layout: Line Budget + LaTeX Renderer & PDF Verification

## Done (with evidence)
- **Template Contract & Injection Markers (`careercompiler/layout/template.py`, `templates/resume.tex`)**:
  - Implemented `ResumeTemplate` parsing hierarchical injection markers (`%%BEGIN:EXPERIENCE:<id>%%`, `%%BEGIN:SLOT:<id>%%` ... `%%END:...%%`).
  - Strict stack-based validation: unclosed markers, mismatched tags, and duplicate slot/entity IDs raise explicit `TemplateSyntaxError` exceptions (no silent guessing).
  - Instrumented canonical `templates/resume.tex` with markers across all 12 slots and 5 entities; confirmed 100% backward-compatibility when compiled with Tectonic CLI.
  - Implemented dynamic rendering with safe bullet injection and clean slot omission.
- **Injection-Safe LaTeX Escaping Engine (`careercompiler/layout/latex_escape.py`)**:
  - Strict escaping for `\ & % $ # _ { } ~ ^ < > | "` and Unicode characters (dashes, quotes, arrows, math symbols `≥`, `≤`, `→`, currency).
  - Control characters `\x00-\x08`, `\x0b-\x0c`, `\x0e-\x1f` sanitized.
  - Shell escape completely disabled; user text cannot emit TeX control sequences or macros.
  - Property-based fuzz tests with Hypothesis verifying that escaped arbitrary text never crashes and compiles cleanly under Tectonic.
- **Empirical Line Budget Model (`careercompiler/layout/budget.py`)**:
  - Empirically calibrated page capacity boundary through compile probes: 30 bullet lines alongside standard fixed sections (header, education, skills, leadership).
  - Integrated `FontMetricSimulator` from Phase P1 (verified 0 under-estimates on 52-bullet ground-truth harness).
  - Implemented `LayoutBudgetModel.evaluate()` reporting line usage, remaining margin, and overflow lines.
- **Isolated Tectonic Runner & Multi-Factor PDF Verifier (`careercompiler/layout/verifier.py`)**:
  - Compiles in isolated temporary directories per build (`tempfile.TemporaryDirectory()`).
  - Surfaces layout warnings (`Overfull \hbox`, `Missing character`).
  - Verifies strict single-page constraint (`page_count == 1`).
  - Verifies Truth Invariant via `pdftotext` with ligature (`fi`, `fl`, `ffi`) and hyphenation line-wrap normalization, guaranteeing that every selected bullet appears in the output PDF.
  - Verifies 100% embedded font compliance via `pdffonts` (`emb == yes`).
  - ATS-friendly text extractability check (>200 extracted characters).
